阶段 1 · 1 概述

程序怎么来

规则①程序由函数构成，只能有一个 main。②步骤：源程序 → 目标程序（编译）→ 连接 → 可执行程序。③注释可出现在任意合适处。

Q1以下错误的说法是__

A一个 C 程序只能实现一种算法
B一个 C 函数可单独作为一个源文件
C程序可由一个或多个函数组成
D程序可由多个程序文件组成
展开答案
答案 A —— 一个程序可以同时实现多种算法、多个函数。

Q2以下错误的说法是__

A用计算机语言写的程序叫源程序
B编译是把源程序翻译成目标程序
C先编码调试，编码中再确定算法
D写完都是先编译、后链接、最后运行
展开答案
答案 C —— 步骤是"先分析问题、设计算法，再编码调试"，算法在编码之前，不是编码中。

Q41以下叙述正确的是__

A注释可出现在程序中任意合适处
B目前只支持 /* */ 一种注释
C所有函数名都可由用户命名
D分号是分隔符，不是语句一部分
展开答案
答案 A —— C 支持 // 和 /* */ 两种注释；main 由系统命名；分号是语句的一部分。

Q82高级语言源程序转成目标程序，要用__

A编辑程序
B驱动程序
C诊断程序
D编译程序
展开答案
答案 D —— "翻译"这一步就是编译。
概述四条规则。程序由函数组成，一个程序只能有一个 main。编译把源程序翻译成目标程序，连接再生成可执行程序。 Q1：A 是错的，因为一个程序可以做好几种算法。考点是"程序由函数构成、可包含多种算法"。 Q2：C 错，"先编码、编码中才定算法"顺序反了，先定算法再写码。 Q41：C 错，main、printf 这类名字不是用户随便命名的。 这几题直接套规则即可。

阶段 1 · 2.2 基本数据类型

数据在内存里怎么存

规则：int 存补码、char 存ASCII 码；C 没有逻辑类型；float/double 以指数形式存放有误差；各类型占字节数由编译系统决定。

ABCD 码
BASCII 码
C原码
D反码
展开答案
答案 B —— char 存 ASCII 码，int 存补码。

Bint 型数据在内存中存的是反码
Cint、char、short 占字节由编译系统决定
Dfloat 以指数形式存放，往往有误差
展开答案
答案 B —— int 存的是补码，不是反码。

Q7关于数据类型，以下错误的说法是__

A准确表示自然数应使用整数类型
B存多位小数用双精度类型
C修饰词只能用于整型和字符型
D只处理真假，应使用逻辑类型
展开答案
答案 D —— C 没有逻辑类型，真/假用 0/非 0 表示。

Q84long、int、short 占用内存大小的叙述，正确的是__

A均占 4 个字节
B根据数据大小决定
C由用户自己定义
D由 C 编译系统决定
展开答案
答案 D —— 字节数由编译系统决定（不同平台可能不同）。
这一页四条规则。int 存补码，char 存 ASCII 码，对应 Q3 和 Q8。 Q7：C 没有逻辑类型，真/假用 0 和非 0 表示。 各类型占字节数由编译系统决定，对应 Q84。 float 以指数形式存放，所以判断"能否精确表示"时会有误差。 这四题都是概念判断，套规则即可。
阶段 1 · 2.3 常量与变量 · ①字符常量

字符常量与转义

规则：字符常量=单引号、只能一个字符；转义用 \ 引导（八进制最多 3 位、十六进制最多 2 位）；大小写差 32：'A'=65、'a'=97。

B包含 2 个字符
C包含 3 个字符
D说明不合法
展开答案
答案 A —— '\72' 是一个八进制转义字符，整体算 1 个字符。

B字符 a
C字符 e
D非法的常量
展开答案
答案 A —— 八进制 101 = 十进制 65 = 'A'。

A'A'
B'a'
C'Z'
D'z'
展开答案
答案 B —— 大写满足条件，+32 变成小写 'a'。大小写差 32，读程序中大小写转换会用到。
字符常量三条规则。第一，单引号里只能一个字符，转义符 \ 后面必须有内容，所以 '\' 编译报错，对应 Q4。 第二，'\72' 八进制转义整体算一个字符，对应 Q47。'\101' 八进制等于十进制 65，是 'A'，对应 Q115。 第三，大小写差 32：'a' 比 'A' 大 32。Q14 是大小写转换，条件成立 +32。 注意大小写差 32，读程序题中大小写转换会用到。

阶段 1 · 2.4 运算符和表达式 · ①优先级

优先级口诀：单算关逻条赋逗

口诀：单目 > 算术(* / % 高于 + -) > 关系 > 逻辑(&& 高于 ||) > 条件 ?: > 赋值 > 逗号。sizeof 是运算符不是函数，跟类型名要加括号。

B+

B++i 是先变后用，i-- 是先用后变
C结合性是自右向左
D若 i 已定义，则 (-i)++ 是合法的

A要整除，/ 两边都要求整型
B要小数，/ 两边都必须实型
C% 两边操作数都必须是整数
D* / % 优先级相同

A-63, -64

C1, -60
D79, 78

答案 B —— 1+'a'=1+97=98；7%-4=3，2+3-65=-60。

阶段 1 · 2.5 类型转换

强制转换只截断，不舍入

规则：(int)x 只取整数部分（截断），x 本身不变；混合运算里任何类型与 float 运算结果都是 double。

Q9程序输出结果是？

Bx=3,i=3
Cx=3.600000,i=3
Dx=3,i=3.600000
展开答案
答案 C —— (int)3.6 截断=3，x 仍是 3.600000 不受影响。
类型转换一条规则：(int)x 是截断，不是四舍五入，3.6 强转 int 得 3。强转只影响转换结果，x 本身不变。 Q9：i=3，x 仍是 3.600000，选 C。强转不改原变量是易错点。 任何类型与 float 一起运算，结果都是 double。

套路：rev = rev*10 + n%10 是经典逆序累加——每次把个位接到新数末尾，n 除以 10 丢掉个位。与套路 1 的拆位同源（x%10 取位、x/10 丢位）。
套路 7 反序数。特征是 while 循环 + 取余拼接。 rev=rev*10+n%10，n 除以 10。5678：先取 8，rev=8；再取 7，rev=87；再 6，rev=876；再 5，rev=8765。 它和套路 1 的拆位是同源技巧：x%10 取位、x/10 丢位。 现场跟着敲：一个 while，三行。

套路 9 · 进制转换（二进制 → 八进制）

真题 #6：输入长度不超过 9 的二进制字符串（0/1），转八进制输出。如 "1011010" → 132。含非 0/1 给"输入出错"提示。

① 读入 + 长度检查
char s[80]; int i, n=0; gets(s); if(strlen(s) > 9){ printf("字符串长度>9,退出。\n"); return 1; }
② 合法性检查（注意是 &&，不是 ||）
for(i=0; s[i]; i++) if(s[i]!='0' && s[i]!='1'){ printf("输入出错\n"); return 1; }
③ 二进制逐位累加为十进制，%o 输出
for(i=0; s[i]; i++) n = n*2 + s[i]-'0'; // n*2 左移一位 + 当前位 printf("%o\n", n);
预期输出输入 "1011010" → 132
常错点：合法性判断必须用 &&（参考答案写成 || 是错的，任何字符都满足）；n=n*2+s[i]-'0' 是二进制累加公式。
套路 9 进制转换。 第 1 步：gets 读入，检查长度不超 9。 第 2 步：检查每个字符是不是 0 或 1，用 &&。参考答案写成 || 是错的。 第 3 步：二进制累加 n=n*2+s[i]-'0'，最后 %o 直接输出八进制。 现场跟着敲：读入、检查、累加、输出。
