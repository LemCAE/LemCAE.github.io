# 趣味人格测试开发指南

测试大厅和测试共用 `lab/index.html`。`catalog.json` 是发布清单，`tests/<id>.json` 包含一套测试的全部内容。浏览器用 `app.mjs` 载入配置、呈现页面并保存进度，`engine.mjs` 校验配置和计算结果，`share.mjs` 用 Canvas 绘制独立的 900 × 1200 分享图。页面继承首页的 `lemcae-theme`。

## 新增并发布测试

1. 在 `lab/tests/` 新建 `<id>.json`。可以复制 [最小阅读测试](tests/fixtures/reading.json) 或 [力学测试](tests/structures.json) 开始。
2. 将封面与人格插图放入 `lab/art/`。配置中的图片路径以 `lab/` 为基准，例如 `art/my-cover.svg`。
3. 从仓库根目录运行 `python3 -m http.server 8000`，打开 `http://localhost:8000/lab/`。用 `node --test lab/tests/engine.test.mjs` 运行引擎检查。
4. 在 `lab/catalog.json` 的 `tests` 数组中加入 ID，例如 `{"tests":["structures","my-test"]}`。大厅按清单顺序展示，直达路径为 `/lab/?test=my-test`。首页已通过 `data/projects.json` 接入大厅，每套新测试只需注册一次。

## JSON 字段

除标注可选的字段外，其余均为必填。同一组内的 ID 不能重复，且只能由小写字母、数字和单个连字符组成。文本字段须有内容。

| 字段 | 定义 |
| --- | --- |
| `id` | 测试 ID，须与配置文件名和大厅清单一致。 |
| `title`、`description` | 测试标题和大厅卡片的简短介绍。 |
| `version` | 版本字符串，例如 `"1.0.0"`。题目、选项、选项顺序或计分规则变更时请升版本，旧进度随后会被忽略。 |
| `intro` | 介绍页的段落数组，至少一段。 |
| `minutes` | 预计完成时间，1–120 的整数。 |
| `cover` | 图片对象，见下方约定。 |
| `theme.dark`、`theme.light` | 分别应用于深色、浅色模式的强调色，使用六位十六进制颜色。 |
| `dimensions[]` | 3–8 个维度。每项有 `id`、`label`、描述两端行为的 `low` 和 `high`，以及可选的匹配权重 `weight`（1–10 的整数，默认 1）。数组顺序决定雷达图和条形图的排列。 |
| `questions[]` | 1–100 题。每题有 `id`、`prompt` 和 2–8 个 `options`。 |
| `questions[].options[]` | 单选项，包含 `id`、`text` 和 `weights`。权重对象以维度 ID 为键，值为 −10 到 10 的整数。省略的维度按 0 计，允许空对象。 |
| `matching.method` | 当前支持 `"weighted-distance"`，由下方公式定义。 |
| `types[]` | 2–40 种人格。每项包含 `id`、`name`、唯一的 `code`、一句话 `summary`、详细 `description`、`image` 和非空字符串数组 `traits`。 |
| `types[].target` | 人格目标向量，以维度 ID 为键，值为 0–100 的整数。须为每个维度填写一个值。 |
| `types[].quote` | 可选，代表语录。 |
| `types[].partner` | 可选，包含同测试内另一个人格的 `typeId` 和说明 `reason`。 |
| `report.labels` | 可选，覆盖报告内置文案。支持 `certificate`（证书标题）、`profile`（解析标题）、`dimensions`（维度标题）、`traits`（主要特征标签）、`partner`（搭档标题）。 |
| `report.sections[]` | 可选，最多 12 项，每项包含 `id` 与 `label`。按数组顺序定义报告栏位，可用于优势、弱点、推荐或其他主题内容。 |
| `types[].sections` | 可选，以已定义的报告栏位 ID 为键，值为一段文本或字符串列表。某种人格缺少栏位内容时跳过该栏位。 |

图片对象由 `src` 和 `alt` 组成。支持本地 SVG、PNG、WebP 和 JPEG。图片应自包含，使用可读的替代文本。横版封面适合约 11:6 的画框，报告插图适合 8:5 的画框。深色强调色宜选亮色，浅色强调色宜选深色，检查正文、描边和按钮文字的对比度。分享图采用固定的浅色证书版式，用浅色主题的强调色与本地人格插图。图中显示前三条特征，文字较长时自动调整字号并截断。

## 设计维度与匹配

每题只选一项。按维度累加答卷权重，并把每一题该维度最小、最大的选项权重分别累加为整卷上下界。每个维度都需要至少一道题提供不同权重，保证上下界不同。

对于某一维度，内部归一化分数为 `round(10000 × (作答总分 − 下界) / (上界 − 下界))`。人格配置中的目标值乘以 100 后，与内部得分处于同一尺度。每个人格的距离为各项 `维度权重 × (归一化分数 − 目标值 × 100)²` 之和。距离最小的人格胜出，完全同距时选配置中排在前面的类型。雷达图和条形图都将归一化分数分成五档，分界位于内部尺度的 2000、4000、6000、8000。档位用于描述本问卷中的行为倾向。

设计题目时，让一个回答可同时反映多种倾向。给每种人格写一条符合日常行为的完整作答路线，用引擎检查其结果，再调整目标向量及权重。测试文件包含八条力学路线和一个未发布的阅读测试，还验证了边界、同距和进度恢复。

进度按测试 ID 和版本存于 `localStorage`。浏览器拒绝写入时，可以在当前页答完，页面会提示进度无法保存。PNG 在本地生成，有文件分享能力时可调起系统分享。浏览器也始终提供下载链接和图片预览。
